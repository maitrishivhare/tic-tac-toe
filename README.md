Tic-Tac-Toe Game Web Application
A responsive and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript.
This project demonstrates core JavaScript concepts such as DOM manipulation, game logic implementation, and event handling while creating a visually appealing web-based game interface.
Project Overview
The Tic-Tac-Toe Game is a two-player browser-based game where players take turns marking X and O on a 3x3 grid. The application detects winning conditions, handles draws, and allows players to restart the game.
Features
Two-player gameplay (Player X and Player O)
Automatic win detection
Draw detection
Game reset functionality
Interactive and responsive UI
Background styling using a custom wooden texture image

Technologies Used
HTML5 – Structure of the game layout
CSS3 – Styling and responsive design
JavaScript – Game logic and interactivity

How the Game Works
Players click on grid cells to place X or O.
JavaScript tracks player turns.
After each move, the game checks for winning combinations.
If a winning pattern is detected, the winner is displayed.
If all cells are filled without a winner, the game declares a draw.
A reset option allows players to start a new game.
